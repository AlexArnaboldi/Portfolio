SHADOWLOOP

What is it?

Multiplayer coop game in which you and your friends have to destroy as much asteroids and satellites as you can in the given time.

When was it made?

Summer 2024, developed in ~3 weeks.

Who made it?

Me on my own.

What did I learn/practice?

  • Multiplayer in Unreal Engine entirely in C++ (framework, replication, RPC, relevancy, sessions...)
  • Creation and management of modules/plugins for clean architecture
  • UI programming in C++
  • Integration with FMOD for sound FX
  • Debugging and tools programming

The Floor is Lava

Third-person platforming Academic project

A didactic third-person platforming prototype developed to practice core functionalities in Unreal Engine 5 using Blueprints. The project explores foundational gameplay systems, interface design, and visual feedback integration.

Role: Game Programmer.
  • Unreal Engine 5
  • Blueprint

Features:

  • Respawn and checkpoint system
  • Gameplay mechanics, including shooting that adapts to player movement
  • Visual effects using Materials, Material Instances, and Niagara particle systems

About Me
