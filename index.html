Golden Souls

Solo Project Unreal Engine - C++ Combat system Animation Complete

Game

Golden Souls is a third-person action RPG inspired by the Souls-like genre. Set in a dark fantasy world, players explore cursed dungeons, wield a variety of melee weapons, and battle monstrous enemies to survive.

Schedule

This solo project was developed to push my skills in Unreal Engine and C++. While I followed a structured Udemy course, I also implemented original features such as a custom bow system and the UEnemySmartAttack component for advanced enemy behaviors and special attacks. The game features an open-world structure with characters and enemies built around attributes like health and stamina. I designed a modular combat system supporting multiple weapon types and animation states. The architecture is primarily written in C++, with selective Blueprint integration to streamline visual scripting and UI logic. Throughout development, I focused on clean code practices, refactoring, and debugging to ensure scalability and performance.

What I Learned

  • Designed an open-world environment using Unreal Engine 5's Landscape and Foliage systems.
  • Built complex Animation Blueprints, retargeted animations, and used Control Rig with inverse kinematics for visual polish.
  • Developed melee combat systems with swords and other weapons, including Motion Warping for root motion animations.
  • Implemented health bars, player stats, and enemy AI with attack logic.
  • Created multiple enemy types, from humanoid warriors to monstrous creatures.
  • Applied best coding practices in C++, including use of data structures, algorithms, and design patterns.
  • Refactored codebase for clarity and maintainability, with strong emphasis on debugging and performance optimization.

Shadowloop

Team Project Unreal Engine C++ Production Pipeline

Game

Shadowloop is a first-person horror puzzle game in which the player must solve environmental challenges to break out of a recurring time loop.

Schedule

The project was developed in a structured team environment, simulating a professional studio workflow with a clear division between designers and programmers. The game features interactive physics-based object rotation, enemy AI, and dynamic level transitions.

You can play it on itch.io.

My Contribution as Game Programmer

  • Developed the core mechanic: teleporting the player in real time to simulate recursive environments.
  • Created the main menu system, including communication between UI elements and in-scene Actors.
  • UI programming in C++.
  • Designed and implemented the in-game UI: pause menu, game over screen, and credits panel.
  • Built a basic save system to store key player progress and game state across sessions.
